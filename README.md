The following projet aims to compare different forecasting methods applied on synthetic data. 
Data is generated with different stochastic processes, going from basic Geometric Brownian Motion to more stylized classes like Heston Model. 
The idea is to capture what mathematical patterns these methods are able to capture. 
The methods used contain : ARMA Calibration, self_supervised OLS, rnn, Transformer, CSDI style score-diffusion model
